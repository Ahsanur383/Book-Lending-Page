# 📚 Book Haven – Online Book Store

Book Haven is a modern and responsive online book selling website designed to provide users with a simple and enjoyable book shopping experience.

## ✨ Features
- Responsive Navigation Bar
- Attractive Hero Section
- Featured Books
- Best Selling Books
- Book Categories
- Special Offers & Discounts
- Customer Reviews
- Book Search Functionality
- Shopping Cart
- Add and Delete Books
- Admin Book Management Section
- Responsive Design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🎨 Design Colors
- Background: Cream White
- Primary: Dark Green
- Buttons: Orange
- Text: Dark Black

## 👨‍💻 Project Purpose
This project is created to practice and improve my frontend web development skills using HTML, CSS, and JavaScript.
